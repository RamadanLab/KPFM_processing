# KPFM_processing
Processing for Kelvin Probe Force Microscopy time series and further image analysis


Grain analysis files: 

CPDGrainBoundaryAnalysis - for dark CPD anaylsis with errors over multiple images. 

SPVGrainBoundaryAnalysis - for plotting CPD of dark, illluminated and recovery and SPV of illuminated and recovery grain boundary/interiour difference.
